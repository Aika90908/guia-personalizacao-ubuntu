MINHA PERSONALIZAÇÃO DO UBUNTU

Este repositório reúne minha personalização do Ubuntu, incluindo temas, ícones, extensões do GNOME, programas instalados e configurações do terminal.

SOBRE O SISTEMA

Distribuição Linux: Ubuntu
Versão: Ubuntu 26.04.1 LTS

Este guia documenta a personalização do meu ambiente Ubuntu. Alguns procedimentos podem variar dependendo da versão do Ubuntu e do GNOME.

OBJETIVO DO PROJETO

Não sei programar, muito menos criar scripts, então decidi documentar manualmente toda a personalização do meu Ubuntu neste passo a passo.

Criei este guia para compartilhar minha personalização com outras pessoas e também para facilitar a recuperação da aparência do meu sistema quando eu precisar formatar o PC ou reinstalar o Ubuntu.

Assim, posso consultar o repositório e seguir novamente as etapas para deixar meu sistema bonito do jeito que gosto, sem precisar lembrar de tudo do zero.

O objetivo é manter um registro simples, organizado e fácil de seguir, sem depender de scripts automatizados.

2. TEMAS E APARÊNCIA

Minha configuração de aparência utiliza:

Cursor do mouse: Deepin
Tema de ícones: Reversal-Pink
Tema do GNOME Shell: Fluent-Purple-Light
Tema de aplicativos legados: Fluent-Purple-Dark
Personalização de pastas: Folder Colors

COMO CONFIGURAR

1. Instale os temas e os ícones a partir de suas fontes originais.
2. Abra o GNOME Tweaks.
3. Selecione o cursor Deepin.
4. Selecione o tema de ícones Reversal-Pink.
5. Selecione Fluent-Purple-Light para o GNOME Shell.
6. Configure Fluent-Purple-Dark para aplicativos legados, quando compatível.
7. Utilize o Folder Colors para personalizar as cores das pastas, caso deseje.

A extensão User Themes permite utilizar temas personalizados para o GNOME Shell. Algumas alterações podem exigir que você encerre e reabra a sessão.

3. EXTENSÕES DO GNOME

As extensões que utilizo são:

COMO CONFIGURAR

1. Instale as extensões.
2. Ative todas as extensões listadas acima.
3. Mantenha as configurações padrão de Blur my Shell, Caffeine, Just Perfection, User Themes e Vitals.
4. Configure a Dhruva seguindo as instruções abaixo.

UBUNTU DOCK

A Ubuntu Dock, extensão que já vem com o Ubuntu, fica desativada. Utilizo a Dhruva como dock principal.

CONFIGURAÇÃO DA DHRUVA

A Dhruva possui configurações personalizadas.

Neste repositório, disponibilizo o arquivo de configuração exportado da Dhruva. Para reproduzir minha configuração:

1. Instale e ative a Dhruva.
2. Localize o arquivo de configuração da Dhruva neste repositório.
3. Abra as configurações da extensão.
4. Utilize a opção de importar configurações.
5. Selecione o arquivo exportado.
6. Confira se o dock ficou como esperado.

ÍCONE DO COELHO DA DHRUVA

Também disponibilizo neste repositório o ícone do coelho utilizado na Dhruva.

Caso o ícone apresente problemas ou precise ser configurado novamente:

1. Localize o arquivo do ícone no repositório.
2. Abra as configurações da Dhruva.
3. Se necessário, selecione manualmente o arquivo do coelho.
4. Confira se o ícone aparece corretamente.

Consulte as pastas do repositório para localizar os arquivos disponibilizados.

4. TERMINAL

Minha configuração de terminal utiliza:

Aplicativo: Ptyxis
Shell: Zsh
Gerenciador do Zsh: Oh My Zsh
Tema: Powerlevel10k
Plugin do Oh My Zsh: git
Opacidade da janela: 30%
Transparência da janela: 70%

COMO REPRODUZIR

1. Utilize o terminal Ptyxis.
2. Instale o Zsh.
3. Instale o Oh My Zsh.
4. Instale o Powerlevel10k.
5. Configure o Powerlevel10k como tema do Zsh.
6. Ative o plugin git na configuração do Oh My Zsh.
7. Ajuste a transparência do Ptyxis para obter o efeito visual desejado.

Pode ser necessário instalar uma fonte compatível com os símbolos utilizados pelo Powerlevel10k.

IMPORTANTE: esta seção documenta os programas e as configurações que utilizo. Os arquivos de configuração do terminal não estão incluídos neste repositório.
